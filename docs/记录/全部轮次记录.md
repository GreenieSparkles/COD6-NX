## 先看这一段：**文件夹编号 ≠ 轮次编号**

这一点必须写在最前面，否则后面看数据会全错：

1. **文件夹名是 `新建文件夹 (NN)`，但 NN 是"复制次数"不是"第几轮"。**
   实测里散落着各种情况：
   - `新建文件夹 (50)` 有**两个**，时间差 8 小时（10-29 10:51 和 10-29 19:16）
   - `新建文件夹 (0)` 有**三个**（10-28 12:18 / 12:27 / 12:43）
   - 中间跳号的地方，多半是那一次崩了/黑屏，没能留下日志

2. **同一个 `fps` 值可能是同一次运行被复制了两遍。**
   最典型：`78`~`85` 全是 `fps=4.23 / frames=854 / dpf=75.6`，这**不是 8 次测试**，
   而是同一次运行的日志被重复复制（那几个文件夹里连 `resumen.txt` 都没有，
   数据是后来从 `cod6_lastrun.log` 里读出来的）。

3. **`version=` 这一行是从 87 号才开始有的。**
   87 之前（0~86）都没版本号，只能靠时间戳和 fps 区分。
   **从 87 号起，`resumen.txt` 第一行就是判据**：
   ```
   cod6 resumen version=2026-10-30-29 (cache de canalizaciones activo)
   ```

4. **本表按文件夹号 + 时间排序**；判断"第几轮"没有意义，**以时间戳为准**。

## 数据可信度说明

1. **`fps` 是 `resumen.txt` 里的平均值**，不是瞬时值。菜单和关卡内差别极大，看 fps 必须配合 `dibujos_por_fotograma`：
   - `dpf≈50~85` → 主菜单
   - `dpf≈5000` → 关卡内
   - `dpf=0` → 跳过绘制
2. **超过频和没超频差约 1.4 倍**，110 号之后用户确认开过超频。跨超频状态比较 fps 没有意义。
3. **78~85 是同一次运行的重复复制**，不能当作 8 次性能数据。
