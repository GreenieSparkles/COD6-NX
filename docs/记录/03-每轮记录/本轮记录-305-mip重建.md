## 一、第一次真正看到卡上的画面

v303 把源码里一直存在、但从没在真机开过的帧捕获打开了。拉回来的东西：

```
cap/frame_000300.rgbx … frame_002100.rgbx    8 张 960x540
cap/tex_f000900_*.img / tex_f001200_*.img    14 张被采样的纹理
logs/rex/rex_stderr.log                      135,802 B
```

解码后（`build\v303_decode.py` / `v303_bc_decode.py`，脚本都留在 build 里）一眼就看到两个毛病：

| 现象 | 放大看是什么 |
|---|---|
| 墙面/水泥块上一层细密方格 | **摩尔纹**（高频纹理被强缩小、只在 mip 0 采样）+ DXT 块边界 |
| 地面一片绿/紫/粉的彩色噪点 | 同上，DXT 4x4 块被压到几个像素 |

**结论：这是走样，不是串图。** 也就是说 `cod6_native_force_mip0` 这个「保险」本身就是画面变差的主因之一。

### 同时被排除掉的两条假设

| 假设 | 怎么排除的 |
|---|---|
| SET_CONSTANT 常量块映射错（交接文档第十章优先 1） | 逐行对照 SDK：基址 `0x4000/0x4800/0x4900/0x4908/0x2000`、索引 `& 0x7FF`、`default` 丢弃 —— 我们的 `ConstantBase` 与 SDK 完全一致 |
| 绑定缓存键漏掉某个采样槽（→ 两个绘制共用描述符集） | v303 新增的 `[binding-key] mask_checked=N mask_missing=0`，12 次采样点全是 0 |

`mask_missing` 这个哨兵留在代码里了（`cod6_native_bind_check`），以后当回归用。

## 二、「运行一会儿卡一下」——是我造成的，已修

v303 每 300 帧捕获一次，每次都要 `vkDeviceWaitIdle` + 往卡上写 2 MB。
按 30 fps 算就是**每 10 秒卡一下**。日志里 `slow frames` 的计数与捕获点对得上。

**v304 起加了 `cod6_debug_capture_max`：抓够就彻底停。v305 设成 5，抓完第 5 帧之后全程零捕获开销。**

顺带记一笔：这一轮实测 fps 是 30 → 26 → 9.2 → 23.7 → 9.9 → 21 → 15.9 → 14.1 → 22.2 → 18.9。
9~10 fps 那两个十秒窗口是关卡加载/编译管线，不是捕获造成的（捕获是单帧尖峰，拉不低十秒平均）。

## 三、v305 的修复：自己重建 mip 链

### 根因链（有证据）

1. 游戏用 **memexport 顶点着色器**把 mip 层拷到位；我们**无条件跳过**这类绘制：
   `[native] memexport vertex shader 4970836A4129BE7D (prim 1, 1024 indices), skipped`
2. 于是 guest 里 mip 1 以上**全零**。
3. 为了不被采到黑，历史上用 `cod6_native_force_mip0 = true` 把所有采样钳在 mip 0。
4. 代价就是 v303 拍到的那些走样。

### 修法

在 `native_textures.cpp` 的解交织（untiling）末尾加一步 `RebuildMipChain()`：

- 以**已经反交织好的 staging 缓冲**里的 level 0 为源
- 2x2 平均逐级下采样
- 再压回**同样的块格式**写进 staging 对应层的偏移
- 支持：**DXT1、DXT3/DXT5、DXN（BC5 法线图）**，以及 4 字节非压缩格式
- **DXT1 的一比特透明保留**（三色模式 + 索引 3 透明）—— 不然树叶和铁丝网在远处会糊成实心方块
- **只写我们自己的 staging 缓冲，绝不碰 guest 内存**（v298 就是拿 guest 内存瞎 memcpy 才炸的）
- 如果 guest 里 level 1 不是全零（说明它自带真 mip），**一个字节都不改**

配置上同时把 `force_mip0` 关掉，让采样真正用上 mip。

### 为什么这样做是站得住的

mipmap 的定义就是 2x2 平均。游戏原本写进去的也是这条链（多半就是 GPU 上的 2x2 平均）。
所以重建出来的图和游戏本意的差别，只在 DXT 重新压缩的误差里，肉眼基本看不出；而它换来的是
**远景不再闪、不再糊格子、彩色噪点消失**。

## 四、怎么跑 / 怎么退

跑：照常进关卡，待 60 秒以上。捕获只在前 5 个点（约第 300…1500 帧）有卡顿，之后没有。

退（如果画面反而变差，两行改回去就行）：

```toml
cod6_native_generated_mips = false
cod6_native_force_mip0 = true
```
