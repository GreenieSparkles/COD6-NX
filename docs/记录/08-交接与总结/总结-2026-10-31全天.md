| 问题 | 答案 |
|---|---|
| 黑屏的真正原因 | 跳过模拟层的 `IssueDraw` = 连"进入渲染目标"都没做 → 绘制无处落地（v137 证实） |
| 缺页风暴是否是瓶颈 | 不是，只有 12 次/秒（210 号） |

| 绘制在哪 | 主环只有寄存器写 + 跳转；绘制在**间接缓冲**里（v123 起跟进） |
| 环几何 | `base=0x1FC98000 bytes=32768`（v111） |
| 菜单只有几个着色器 | **4 个**，其中 `A4A9` 占 68% |

## 三、今天踩的坑（每条都烧了至少一轮）

| 坑 | 现象 | 教训 |
|---|---|---|
| 在构造函数里打日志 | 一行都没有 | 日志未初始化，写在配置里会丢 |
| 引用不存在的 SDK 接口 | `InitializeRingBuffer` 从没被调用 | 环几何要从 `primary_buffer_ptr_` 取 |
| 把钩子挂在没人实例化的类上 | `BUCLE117` 一行没有 | 先确认哪个类真在跑（`LECTOR111` 是证据） |
| 在热路径加日志/格式化 | 黑屏（v128） | 热路径只能放整数运算 |
| 跳过 `IssueDraw` 直接发绘制 | 黑屏（v137） | **它会进入渲染目标；必须先有 `BeginPass`** |
| 每轮只验证一件事 | 几十轮全耗在验证上 | 应一次做完一个完整模块 |
| 黑屏就回退再发包 | 手上堆了 v136~v140 | 实验路径必须自带"状态不对就落回"的保护 |

## 四、正确路线（明天第一件事）

**一次做完，不发中间验证包：**

```
src/native/cod6_native_destinos.*   渲染目标缓存（v140 已有骨架：DestinoKey + DestinoCache）
src/native/cod6_native_pass.*       BeginPass：自己开 render pass + barrier + 布局
src/native/cod6_native_lote.*       连发：同一管线的 A4A9 多次绘制一次发出
                                     保护：状态不一致 → 整条落回模拟层
```

**验收**：画面与 v138 一致 + fps 上升。
**没有中间态**：这三件不齐，就一定黑屏（v137 已经证明）。
